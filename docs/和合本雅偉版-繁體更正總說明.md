# 和合本雅偉版 繁體 — 更正總說明

**給 Raymond 牧師**　2026-09-14

附件：`雅偉版繁體-全部更正.tsv`，17,682 行，每一行是一個字的位置，
帶書卷、章、節、原作、現作、類別、依據、上下文。下面是這份清單的
說明——為什麼動、憑什麼動、哪些**沒有**動。

---

## 一、先講一件前提，因為整件事都建立在它上面

**這個譯本從來沒有繁體母本。**

這不是推論，是編務檔案自己寫的：「繁体从来没有人给过母本，是用
订正表与转换表/tc/ 转出来再逐节校的」。也就是說，貴方手上的繁體，
和我們手上的繁體，**是同一份簡體的兩次轉換**，不是原件和抄件。

這件事決定了方法。兩份轉換在某個字上不一致的時候，
**誰轉得多、誰內部一致，都不是證據**——兩邊都可能錯，而且都錯得很
自洽。所以我們不拿兩份轉換互相比，改拿**印刷版和合本**來對：
和合本雅偉版就是和合本把神名還原，那一節是同一句話，印刷版印的
是哪個字，就是答案。

權威用的是信望愛（bible.fhl.net，`VERSION4=unv`，繁體和合本），
一章抓一次，逐節讀。這次總共讀了 **1,303 章**。

## 二、四類更正，17,682 處

| 類別 | 處數 | 一句話 |
|---|---|---|
| 香港字形 | 15,062 | 整套字形改用香港和合本，不是台灣的 |
| 麽 → 麼 | 1,221 | 「麽」不是任何轉換路徑的輸出 |
| 128 類逐處裁決 | 1,111 | 兩份轉換分歧的字，逐一讀印刷版和合本 |
| 回退複查 | 287 | 一次「整類回退」的淨結果，其中大部分後來又改了回來 |
| 字序更正 | 1 | 耶利米書 4:22 的「我」錯置一句 |

### 1. 香港字形（15,062 處）

業主的裁定是「按照香港和合本的繁体字」。這跟貴方轉換說明裏寫的是
同一件事：**「Hong Kong, at the church's request: 裏, 牀, 着 —
not Taiwan's 裡, 床, 著」**。我們這邊原先除了「裏」之外，其餘都走
了台灣那條路。

十八個字：

```
說→説  著→着  衛→衞  脫→脱  群→羣  戶→户  悅→悦  臥→卧  床→牀
鉤→鈎  稅→税  溫→温  啟→啓  兌→兑  峰→峯  敘→敍  銳→鋭  蔥→葱
```

這十八對**不是憑印象列的**：是把同一份簡體丟進本機安裝的 OpenCC，
分別跑 `s2hk` 和 `s2tw`，比對兩邊輸出的差集得出來的。另有四個候選
被剔除——**梁/樑、痴/癡、灶/竈、麵/麪**——因為兩套設定給的答案一樣，
那就不是地區字形問題，是用詞問題，不能混在一起處理。

也**不是重新跑一次轉換**。整份重轉會把這個譯本自己修過的地方一併
沖掉（創世記 41 的「乾瘦」、「准許」、「指證」等等）。只有這十八個
字動了。

### 2. 麽 → 麼（1,221 處）

這一條其實不是取捨，是這個字形本身站不住：OpenCC 的基礎表
`STCharacters` 把「么」直接映到「麼」，`HKVariants` 和 `TWVariants`
都不產生「麽」。**沒有任何一條轉換路徑會輸出「麽」。**
印刷版和合本作「甚麼」（創世記 2:19）。

### 3. 128 類逐處裁決（1,111 處）

這是主體工作。兩份轉換在 128 個字類上分歧，共 2,046 個位置
（本專案另有 72 個位置是我們這邊獨有的）。全部逐一去讀印刷版和合本
在**那個位置**印的是什麼。

結果，這 2,046 個位置的帳是平的：

| 印刷版和合本印的是 | 處數 | 做法 |
|---|---|---|
| 我們這一邊的字 | 929 | 不動 |
| 貴方那一邊的字 | 1,110 | 改 |
| 第三種寫法 | 6 | 不動，記錄在案（見下） |
| 沒有對應位置 | 1 | 不動（使徒行傳 27:33） |

（附件裏這一類是 1,111 行：以西結書 23:44 那一節同時出現兩種寫法，
在清單上佔兩行。）

**逐處，不是逐類。** 這一點是整件事最要緊的地方，也請您特別看一眼，
因為和合本自己並不一致：

- 出埃及記 25:13 印「**槓**」，27:10 印「**杆**」——同一副杠。
- 以西結書 23:44 一節之內先「**茍**合」後「**苟**合」。
- 撒母耳記上 21:13 印「**胡**寫亂畫……流在**鬍**子上」；約伯記 41:32
  印「隨後**發**光……如同白**髮**」；詩篇 65:13 印「**谷**中……五**穀**」
  ——這三節跟全書其他地方剛好相反。
- 「擡/抬」152 處裏，和合本 150 處作「抬」，撒迦利亞書 1:21 作
  「**擡**頭」。

任何一個整類裁決，都會把上面每一處少數的寫法改錯。所以清單是
**一行一個位置**，不是一行一個字類。

有 **7 個位置和合本印的是第三種寫法**——柺（撒迦利亞 8:4、馬太 10:10、
馬可 6:8、路加 9:3）、矇（以賽亞 29:18「迷矇」）、甘（使徒 8:27
的人名「甘大基」）。這七處**原樣不動**，記錄在案：採用一個兩份轉換
都沒產生過的字，是替譯本造字，不是校對。

還有 **1 個位置查不到**：使徒行傳 27:33，我們作「懸望一直挨餓」，
和合本作「懸望忍餓」——這是措辭差異，那個位置在和合本裏沒有對應
的字，所以標「找不到」，沒有動。

### 4. 回退複查（287 處淨值）—— 這一段是我們自己的錯，寫出來

過程裏有一次**整類回退**，五對字各只憑一節經文定案：

```
藉 → 借   依據 出埃及記 22:14
蔔 → 卜   創世記 44:5
製 → 制   創世記 4:7
沈 → 沉   創世記 2:21
淩 → 凌   士師記 19:25
```

**出埃及記 22:14 講的是借貸**，那裏「借」當然對。可是同一次掃描，
把「耶和華**藉**摩西吩咐」也一併改成了「雅偉**借**摩西」——**151 處**。

發現的方式，跟上面是同一套：把這五對字的**全部 638 個位置**拿去逐節
重讀印刷版和合本。結果是

> 對 486　錯 152　都不是 0　找不到 0

152 處裏 151 處是「借」應作「藉」，剩下 1 處是全書僅存的一個「沈」
（馬太福音 14:30「將要沉下去」）。**另外四對字在它們全部 486 個位置
上都是對的**——出埃及記 22:14 那個答案本身沒錯，錯在拿它去管一個
和合本寫法不同的義項。

**而且反過來掃也是錯的。** 和合本自己有兩處工具義用「借」：
撒母耳記下 12:9「你**借**亞捫人的刀殺害赫人烏利亞」、
約伯記 34:20「有權力的被奪去非**借**人手」——這兩處我們本來就作
「借」，一律改「藉」會把它們弄壞。所以還是逐處。

順帶：申命記 27:15，和合本印「有人**製造**耶和華所憎惡的偶像」，
那次回退把它改成了「制造」，全書 41 個「製造」只有這一處被動到。
已改回。

### 5. 字序更正（1 處）

耶利米書 4:22。和合本作「我的百姓愚頑，**不認識我**；他們是愚昧
無知的**兒女**」。我們這邊的「我」錯置了一句，變成「不認識；……
愚昧無知的**我**兒女」。**貴方的簡體本身是對的**，是我們這邊繁體
的問題，已照簡體改正。

## 四、附帶一句，關於方法

這次一共推翻了我們自己三個先前的判斷，每一個都曾經「有測量、有數據、
而且很自信」：

1. 「我們的字形是對的」——根據是**台灣**出版的和合本。地區問題拿錯了
   證人。
2. 「兩份轉換互相對照就能定案」——不能。兩邊都是轉換。
3. 「一節經文可以定一整類字」——不能，和合本自己就不一致。

三次都是同一個毛病：**用統計代替閱讀**。所以最後這份清單是 1,303 章
一節一節讀出來的，慢，但是每一行都能指回一句印出來的經文。
