# 和合本雅偉版 繁體 — 两个转换的对照

2026-09-14。

这不是「谁比较新」的问题。这个译本**从来没有繁体母本**，
两边都是从同一份简体转出来的，所以是两个转换在互相对照，
不是原件和抄件。简体是证人：两边在哪个字上分歧，就看那个字
在简体里本来是什么。
